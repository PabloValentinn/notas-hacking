
## DESCRIPCION
- This [.tar file](https://challenge-files.cylabacademy.net/library/0fcc092f4e3d0027bc89f6de85e2b750462dca0a96c5643e38e5825e2da1c3d2/1000.tar) got tarred a lot.

## SOLUCION
```

- Se descargó el archivo comprimido inicial llamado `1000.tar`.
    
- Analizando la pista de la descripción ("tarred a lot"), se dedujo que el archivo era una "matrioska": estaba empaquetado 1000 veces, conteniendo el archivo `999.tar` dentro, el cual contenía el `998.tar`, y así sucesivamente.
    
- Para evitar extraer los archivos uno por uno manualmente, se creó un directorio de trabajo aislado y se ejecutó un bucle `for` en la terminal de Kali Linux para automatizar el proceso:
    
    `for i in {1000..1}; do tar -xf $i.tar; rm $i.tar; done`
    
- El script iteró en cuenta regresiva desde el 1000 hasta el 1. En cada paso, el comando `tar -xf` extrajo el contenido y el comando `rm` eliminó el archivo empaquetado anterior para no llenar el disco de archivos basura.
    
- Al finalizar el bucle, el comando `ls` reveló los archivos finales desempaquetados: un archivo de relleno (`filler.txt`) y una imagen (`flag.png`).
    
- Se visualizó la imagen `flag.png` utilizando un visor gráfico del sistema operativo, la cual contenía la bandera escrita en ella.
```

## NOTAS ADICIONALES
- - **Automatización en Bash:** Este reto es un excelente ejercicio para demostrar la necesidad del _scripting_ básico. Tareas que tomarían horas de forma manual pueden resolverse en segundos encadenando comandos con punto y coma (`;`) dentro de un bucle `for`.
    
- **Gestión de espacio:** Es vital la instrucción `rm $i.tar` dentro del bucle. Sin ella, el sistema conservaría las 1000 copias desempaquetadas, desperdiciando espacio innecesario en el disco duro.
    
- **Uso de `tar`:** Las banderas utilizadas fueron `-x` (extract) para extraer los archivos y `-f` (file) para indicarle al comando el nombre del archivo específico sobre el que debía operar.
