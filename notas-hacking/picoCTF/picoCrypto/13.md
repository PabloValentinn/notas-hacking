
## DESCRIPCION
- Cryptography can be easy, do you know what ROT13 is? `npnqrzl{abg_gbb_onq_bs_n_ceboyrz}`

## SOLUCION
```


- Se analizó la descripción del reto, la cual provee explícitamente el texto cifrado `npnqrzl{abg_gbb_onq_bs_n_ceboyrz}` y sugiere la aplicación directa del algoritmo ROT13.
    
- Para decodificar el mensaje de manera eficiente sin necesidad de herramientas externas o scripts de Python, se utilizó la terminal de Linux haciendo uso de la utilidad de traducción de caracteres `tr`.
    
- Se ejecutó el comando `echo "npnqrzl{abg_gbb_onq_bs_n_ceboyrz}" | tr 'a-zA-Z' 'n-za-mN-ZA-M'`, el cual toma cada letra ingresada y la sustituye sistemáticamente por la letra que se encuentra 13 posiciones más adelante en el alfabeto.
    
- La terminal devolvió inmediatamente el texto en claro, revelando la bandera final del reto: `academy{not_too_bad_of_a_problem}`.
```

## NOTAS ADICIONALES
- Criptografía Involutiva y Herramientas Unix: ROT13 es una variante específica del Cifrado César clásico. Dado que el alfabeto inglés tiene exactamente 26 letras, rotarlas 13 posiciones posee una propiedad matemática de simetría (es una función involutiva). Esto significa que la misma acción exacta que se usa para cifrar el texto sirve para descifrarlo (13 + 13 = 26, regresando al punto de origen). Por otro lado, la resolución de este reto destaca la flexibilidad y el poder de las tuberías (_pipes_) y las herramientas nativas de manipulación de texto en sistemas tipo Unix, como `tr`, para resolver problemas de codificación de forma inmediata.
